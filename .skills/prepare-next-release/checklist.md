# Prepare Next Release Checklist

## Prerrequisitos

- [ ] La release anterior en `specs/releases/` tiene status **Completed** (si existe).
- [ ] El usuario aprobó explícitamente la release anterior.
- [ ] Las features asignadas existen en `specs/013-product-backlog.md`.

## Documentación Revisada

- [ ] Se leyó completamente `specs/013-product-backlog.md`.
- [ ] Se leyó `AGENTS.md`.
- [ ] Se leyó `specs/012-definition-of-done.md`.
- [ ] Se leyó `specs/002-functional-requirements.md`.
- [ ] Se leyó `specs/004-data-model.md`.
- [ ] Se leyó `specs/005-ui-specifications.md`.
- [ ] Se leyó `specs/007-system-architecture.md`.
- [ ] Se leyó `specs/009-project-standards.md`.
- [ ] Se leyó `specs/010-repository-structure.md`.

## Release Validada

- [ ] Se identificó correctamente la release solicitada.
- [ ] La release existe en el Product Backlog.
- [ ] Se identificaron las features asignadas a la release.
- [ ] Se leyó completamente la definición de cada feature.

## Dependencias Analizadas

- [ ] Se identificaron las dependencias técnicas para cada feature.
- [ ] Se verificó que las dependencias están disponibles.
- [ ] Se documentaron las dependencias faltantes (si las hay).

## Riesgos Evaluados

- [ ] Se identificaron los riesgos potenciales.
- [ ] Se evaluó la probabilidad de cada riesgo.
- [ ] Se evaluó el impacto de cada riesgo.
- [ ] Se definieron estrategias de mitigación.

## Archivo de Release Creado

- [ ] Se creó el archivo `specs/releases/RELEASE-X.X.md`.
- [ ] Se estableció el **Status** en `Ready for Development`.
- [ ] Se estableció el **Release** con el nombre correcto.
- [ ] Se estableció el **Objective** basado en las features.
- [ ] Se estableció el **Features** con la lista de funcionalidades.
- [ ] Se estableció el **Scope** basado en las features.
- [ ] Se estableció el **Out of Scope** con las exclusiones.
- [ ] Se estableció el **Dependencies** con las dependencias.
- [ ] Se estableció el **Risk Assessment** con los riesgos.
- [ ] Se estableció el **Acceptance Criteria** basado en las features.
- [ ] Se estableció el **Deliverables** con los entregables.
- [ ] Se estableció el **Definition of Done** con los criterios.
- [ ] Se estableció el **Expected Output** con el resultado.
- [ ] Se estableció el **Stop Condition** con las instrucciones.
- [ ] Se estableció el **Rollback Plan** con el plan de reversión.

## Validación Final

- [ ] El formato del documento es correcto.
- [ ] Toda la información coincide con el backlog.
- [ ] No se omitió ninguna sección.
- [ ] Las dependencias están documentadas.
- [ ] Los riesgos están evaluados.
- [ ] Los criterios de aceptación son medibles.
- [ ] Los deliverables son alcanzables.
- [ ] El rollback plan es viable.
- [ ] El documento está listo para ser revisado.
