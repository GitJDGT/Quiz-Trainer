# Project Overview

## Nombre del proyecto

Quiz Trainer

## Objetivo

Desarrollar una aplicación web ligera que permita practicar un banco de preguntas de opción múltiple de forma interactiva.

El sistema está orientado al estudio y repaso de exámenes, ofreciendo una experiencia rápida donde cada pregunta se responde de manera individual.

Después de responder una pregunta, el sistema únicamente informará si la respuesta fue correcta o incorrecta, sin revelar cuál era la respuesta correcta.

El orden de las preguntas deberá ser aleatorio en cada sesión, incluyendo aquellas que contengan imágenes.

## Público objetivo

Inicialmente el proyecto está diseñado para un único usuario que desea practicar un examen de aproximadamente 210 preguntas.

No obstante, la arquitectura deberá permitir ampliar fácilmente el banco de preguntas en el futuro.

## Alcance inicial

La primera versión del sistema deberá:

- Cargar un banco de preguntas desde un archivo externo.
- Mostrar una pregunta por pantalla.
- Soportar preguntas con o sin imagen.
- Permitir seleccionar una única respuesta.
- Informar inmediatamente si la respuesta fue correcta o incorrecta.
- Continuar con la siguiente pregunta.
- Mostrar el resultado final al terminar la sesión.
